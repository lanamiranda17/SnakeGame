# Snake Game 🐍

Jogo da cobrinha desenvolvido para a Atividade Prática 1 da disciplina GAC116 - Programação Web.

## Objetivo

O objetivo do jogo é controlar a cobra pelo tabuleiro, coletando as comidas para aumentar a pontuação e o tamanho da cobra. A cada ponto obtido, um novo obstáculo é adicionado ao tabuleiro.

## Regras

* Utilize as setas do teclado para movimentar a cobra.
* Colete a comida vermelha para ganhar pontos.
* A cada comida coletada, a cobra cresce e um novo obstáculo aparece.
* A cobra pode atravessar as bordas do tabuleiro e aparecer do lado oposto.
* O jogo termina caso a cobra colida com o próprio corpo ou com um obstáculo.
* O botão "Reiniciar Jogo" inicia uma nova partida.

## Tecnologias utilizadas

* HTML
* CSS
* JavaScript
